Tipos de servidores web


Les mencionaremos los distintos tipos de servidores que existen y el uso que se les da:

  • Servidor web estático: Solo entrega archivos (HTML, CSS, imágenes). No procesa lógica.
  • Servidor web dinámico: Genera contenido en tiempo real usando lenguajes como PHP, Python o JavaScript.
  • Servidor proxy: Actúa como intermediario entre cliente y servidor, mejorando seguridad y rendimiento.
  • Servidor de aplicaciones: Ejecuta la lógica del sistema (por ejemplo, apps web complejas).
    • Software
  • Apache HTTP Server: Es uno de los más utilizados. Es flexible, de código abierto y compatible con muchos sistemas
  • Nginx: Muy rápido y eficiente, ideal para sitios con mucho tráfico.
  • Microsoft IIS: Servidor de Microsoft, común en sistemas Windows
  • LiteSpeed Web Server: Destaca por su alto rendimiento y optimización para WordPress.
    • Función
    Arquitectura
  • Servidor monolítico: Todo funciona en un solo sistema.
  • Servidor distribuido: Varias máquinas trabajan juntas para responder solicitudes.
  • Servidor en la nube (cloud): Se ejecuta en plataformas como Amazon Web Services o Google Cloud.
    • Protocolo
  • HTTP/HTTPS (los más comunes)
  • FTP (transferencia de archivos)
  • SMTP(correo electrónico)

    Hardware

    Les mencionaremos los distintos tipos de servidores que existen y el uso que se les da:


    Servidores web (hardware principal):

    Son computadoras potentes donde se almacenan las páginas web:

  • Guardan archivos como HTML, CSS, imágenes, bases de datos, etc.
  • Están conectados a internet las 24 horas.

    • Ejemplo: servidores de empresas como Amazon Web Services o Google Cloud.


    Dispositivos del usuario

    Son los equipos desde donde las personas acceden a la web:

  • Computadoras (PC o laptops). y Tablets
  • Smartphones.
  • Tablets

    • Equipos de red

    Permiten la comunicación entre el usuario y el servidor:

  • Routers: dirigen el tráfico de internet
  • Switches: conectan dispositivos dentro de una red
  • Modems: conectan la red con el proveedor de internet

    • Sistemas de almacenamiento

    Son los discos donde se guarda la información de la web:

  • HDD (discos duros tradicionales)
  • SSD (más rápidos y modernos)

    • Centros de datos

    Son instalaciones donde se encuentran muchos servidores trabajando juntos:

  • Tienen sistemas de refrigeración
  • Energía constante
  • Seguridad física

    Lenguajes de programación web

    Son la base para crear una página web.

  • HTML: estructura del contenido
  • CSS: diseño y estilos
  • JavaScript: interactividad y dinamismo

  • Mozilla Firefox

    • Sistemas de gestión de contenido

  • WordPress
  • Joomla!

    Solicitud del usuario

    Todo inicia cuando el usuario:

  • Escribe una URL (por ejemplo:google)
  • O hace clic en un enlace

    • Envío de la petición

    El navegador envía una solicitud a través de internet:

  • Pasa por routers y redes
  • Llega al servidor donde está alojada la página

    • Procesamiento en el servidor

    El servidor recibe la solicitud y actúa:

  • Busca los archivos necesarios
  • Usa software como Apache HTTP Server o Nginx
